# ChucK Test Suite
A small suite for running unit tests in ChucK.

## Usage
1. Clone the project.
    - `git clone git@github.com:tdug/ChuckTestSuite.git`
1. Install locally. (One day this package may be registered with the ChucK team.)
    - The Makefile has some useful commands for this.
